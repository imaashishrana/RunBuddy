## 📖 About

RunBuddy is a community-driven running platform designed to help people stay active by connecting with nearby runners and running groups.

Users can create profiles, upload avatars, discover running communities, and participate in local running events—all in one place.

---

## ✨ Features

- 🔐 Secure Authentication using Supabase
- 👤 User Profile Management
- 📷 Avatar Upload
- 🌍 Discover Nearby Running Groups
- 🤝 Join or Create Running Crews
- 📍 Location-Based Running Sessions
- 📱 Fully Responsive Design
- ⚡ Fast Navigation with TanStack Router
- ☁️ Cloud Backend powered by Supabase

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/imaashishrana/RunBuddy.git
```

### Navigate to Project

```bash
cd RunBuddy
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root.

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

### Run Development Server

```bash
npm run dev
```
